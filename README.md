# APEX-3D 封裝試點線

CoWoS 類（Chip-on-Wafer-on-Substrate）先進封裝**培訓原型**。虛構廠區「APEX-3D 封裝試點線」，產品 HBX-100，流程代號 `HBX-100-COW-WOS`。不是任何真實晶圓廠或原廠產品的數位雙生，也不會寫回 MES / ERP。CoWoS 只是工藝族通稱。

v4 把 v3 的五站拆成 **21 個工步**，仍收在原來的五個製程區裡：來料、CoW、切割、WoS、植球／終測／包裝。沒有第六個製程區。電子倉庫和天車是廠務，不是製程站。譜系、MES 狀態、形態、配方、倉庫與天車都讀 `js/route.js`（配方本體在 `js/recipes.js`，由 route 匯入）。沒有第二套狀態機。

## 和 v3 的合約差異

- 電漿是這條路線上的機台（PLS-11）。v3 寫過「這條路線沒有電漿站」，v4 取消那條註記。
- 鍵合偏移改在疊對量測 MET-23 偵測，不再掛在 HB-21。重做回到混合鍵合，再退火、再量測。電漿可以重跑，預設不重跑。
- 底部填充空洞改在點膠 UF-05 發生，不再掛在植球／終測／包裝。重做只重點膠。
- 翹曲改在 MET-07 量測，不再只在 WOS-04 偵測。重做回到 WoS，再點膠、固化、量測。
- 形態多了減薄、已固化填充、已植球：`bank → issued → bonded → thinned → singulated → wos → underfilled → balled → packed`。
- 每步正好一台設備、一張配方。配方是物件，帶 3–6 個參數（名稱、數值、單位），不是只有代號。

HOLD 約在該工步製程的 0.42 凍結。開著的時候形態不往下提交，載具鎖在當站，天車不能送到別的製程機。可以退回倉庫。

重做：

- 鍵合偏移 → HB-21，接著退火、再疊對。
- 空洞 → UF-05 重新點膠。
- 翹曲 → WOS-04，接著點膠、固化、再量測。

回到某步的起點時，形態跟流程位置走。鍵合重做會先回到「已發料」，等 HB-21 再次做完才重新提交 bonded。減薄和切割在偏移關掉之前都不會提交。

## 電子倉庫

走道西端一座自動倉，四個庫區：

| 庫區 | 放什麼 | 載具 |
| --- | --- | --- |
| DBK | KGD／晶粒倉托盤 | TRAY |
| INT | 中介層 FOUP | FOUP |
| SUB | 基板 magazine | MAG |
| FG | 完成的 JEDEC tray | TRAY |

FRAME 不是庫區。貼膜上框時，FOUP 退回 INT，FRAME 在 MNT-80 出現，一直當批次載具，直到 WoS 這邊換成 tray。空框架留在 WOS-04 的單元口，不入庫。

庫存狀態是 `在庫 / 預留 / 在途 / 鎖定`。位置另記。

- 來料檢驗先領 INT 的中介層 FOUP。來料區不發基板。
- 晶粒倉要處理之前，必須發出 DBK 的 KGD，並且中介層 FOUP 已經在手上。DBK 沒有可發的 KGD 時，出庫直接拒絕，天車不會取走沒發出來的托盤。
- 基板 magazine 在基板預烘之前才從 SUB 發出，不是在晶粒倉發。
- 入盤之後，成品 tray 入 FG。
- 區內工步之間用天車搬，不瞬移。

## 天車

天軌是單向迴路，每一台製程機都有裝載口。兩台車。模式沿用 v3 的說法：**自動派車**、**手動叫車**、**暫停**。

一趟搬送：建立需求 → 空車走到來源 → 下降耦合（這時才改成在途）→ 沿天軌走 → 到站下降脫鉤 → 交接進機台之後，製程動畫和形態才開始。載具類型不符就拒絕。HOLD 開著時可以做完當下的升降，或把載具退回倉庫，不能送到下一台製程機。

## 底色

右下角相機列上方有「底色」，三個預設，切過去立刻改 3D 場景，不用重新載入：

- **淺色潔淨室**（預設）：淺灰地板、淡青灰天空，機台和載具比較容易看清。
- **中性灰**：介在淺色和深色之間的廠房灰。
- **深色**：沿用 v5 的深底（清色／霧 `0x071016`、原來的地板和燈光）。

選擇存在瀏覽器 `localStorage`，鍵名 `apex3d-theme`。沒有存過、或存的值不是這三個之一，就用淺色。會改天空、霧、地板、製程區色塊、牆、裙板和燈光。不會改機台位置、21 步流程或配方。步行、跟隨批次、跟隨天車、總覽都用同一套底色。

## 怎麼打開

本頁是 ES modules，請用靜態伺服器，不要用 `file://`。Three.js 在 `vendor/`，沒有新的執行期 CDN。

```bash
cd cowos-packaging-sim
python3 -m http.server 8765
```

瀏覽器開 <http://127.0.0.1:8765/>。介面預設繁體中文（封裝試點線），可切簡體（封装试点线）與 English。

空白鍵推進，R 重播當前工步，F 跟隨批次，3 跟隨天車，1 總覽，2 看當前站。右下角可以切到**步行參觀**：人站在倉庫這一端的走道上，WASD 或方向鍵在地板上走，Shift 加快，點畫面鎖定視角，Esc 解除。走近機台或倉庫出入口會亮起那一台，並打開左邊的機台狀態（狀態、靠港載具、批次形態、配方參數、開著的 HOLD）。步行不暫停自動走線，也不暫停兩台天車。回到總覽會重新打開軌道相機。空白鍵在步行時仍推進批次，不會把人跳起來。

## 刻意留著的限度

- 這是這條 HBX-100 路線用到的設備，不是一座真實工廠的全部機台。
- 3D 用一顆主疊晶加三顆同伴表示單顆化。批次紀錄仍是 12 個 site。
- 機台循環大約 2.6–3.4 秒，是訓練節奏，不是設備節拍。
- 步行是眼高的觀察。人走在五個製程區之間的走道、倉庫出入口和機台旁邊，不會飛、不會爬上機台或天軌，也不會搭天車。
- 機台和載具的細部是程式裡的幾何，不是掃描模型。批次紀錄仍是 12 個 site；畫面上是一顆主疊晶加同伴。
- 翹曲重做若選「烘烤整平」，留在量測站把 HOLD 關掉，不自動退回 WoS。退回 WoS 是另一個「重做」按鈕。
- 沒有 Camstar／MES／ERP 寫回。不要在這個倉庫裡打開 GitHub Pages 或改倉庫設定；Pages 已從 main 的根目錄發布。
